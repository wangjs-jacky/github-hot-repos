# vorssaint/vorssaint-utils

Free and open-source macOS menu bar toolkit.

项目定位  
一个为 macOS 设计的免费开源菜单栏工具包，提供多种系统级功能，提升用户操作效率。

核心功能  
- 实现 alt-tab 切换窗口  
- 提供应用卸载功能  
- 支持系统监控与保持唤醒  
- 集成音量混音器和 Finder 工具  
- 适配 Swift 和 SwiftUI 开发框架

技术特点  
使用 Swift 编写，兼容 AppKit 和 SwiftUI，注重性能与系统集成，代码结构清晰，适合 macOS 开发者快速构建实用工具。

适用场景  
- 开发 macOS 系统工具或实用程序  
- 优化日常操作流程，提高工作效率  
- 为开发者提供可复用的菜单栏组件  
- 实现系统级功能如窗口切换、应用管理  
- 构建轻量级的 macOS 应用程序

推荐理由  
功能丰富且开源，适合 macOS 开发者快速实现系统级工具，提升用户体验，同时具备良好的扩展性和维护性。
