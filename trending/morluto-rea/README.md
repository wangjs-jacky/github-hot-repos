# morluto/rea

Reverse engineer anything with agents, from app behavior down to native binaries.

项目定位  
一个用于逆向工程的工具集，通过代理技术分析应用程序行为及原生二进制文件，适用于安全研究和漏洞挖掘。

核心功能  
- 通过代理进行应用行为分析  
- 支持二进制静态分析与反编译  
- 提供命令行接口（CLI）操作  
- 集成 Ghidra、Hopper 等逆向工具  
- 支持自定义插件扩展功能

技术特点  
基于 TypeScript 构建，具备良好的可扩展性和跨平台能力，结合 AI 代理技术提升逆向效率，支持多种逆向分析工具集成。

适用场景  
- 安全渗透测试  
- 漏洞研究与分析  
- CTF 比赛中的逆向挑战  
- 软件行为逆向追踪  
- 二进制文件静态分析

推荐理由  
适合安全研究人员和逆向工程师使用，提供强大的逆向分析工具链，支持自动化与插件扩展，提升逆向效率与准确性。
