# thaw-app/Thaw

The menu bar manager for macOS

**项目定位**  
Thaw 是一个 macOS 菜单栏管理工具，用于简化和自定义系统菜单栏中的图标与功能，提升用户操作效率。

**核心功能**  
- 管理和隐藏 macOS 菜单栏中的应用图标  
- 自定义菜单栏布局与行为  
- 支持快捷键快速切换菜单栏状态  
- 提供简洁的 UI 界面进行配置  

**技术特点**  
使用 Swift 和 SwiftUI 开发，专注于 macOS 平台，具备良好的性能和现代化的界面设计，支持最新的 macOS 特性。

**适用场景**  
- 需要清理或优化菜单栏的用户  
- 希望提高工作效率的开发者或设计师  
- 使用 macOS 的日常办公用户  
- 对系统界面有个性化需求的用户  

**推荐理由**  
Thaw 以轻量、高效和易用著称，适合希望简化 macOS 操作体验的用户，是提升桌面整洁度和操作效率的实用工具。
