# Hmbown/Codewhale

Open-source coding agent for your terminal, built in Rust and on a journey of continuous community improvement. Issues and PRs welcome.

项目定位  
Codewhale 是一个开源的终端代码代理工具，旨在通过 AI 技术提升开发者在本地环境中的编码效率。

核心功能  
- 通过 AI 协助编写、调试和优化代码  
- 支持多模型和多代理协作  
- 提供命令行界面（CLI）与终端用户交互  
- 集成本地开发流程，强调隐私和安全性  

技术特点  
使用 Rust 编写，注重性能与安全性，支持多代理架构和本地优先设计，适合构建高效、可扩展的 AI 编程助手。

适用场景  
- 本地开发环境中的智能代码辅助  
- 多模型协同编程任务  
- 开发者提升编码效率和质量  
- 对隐私要求高的开发场景  

推荐理由  
Codewhale 是一个高性能、开源且持续改进的终端代码代理工具，适合希望提升本地开发效率的开发者和团队。
