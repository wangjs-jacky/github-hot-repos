# titanwings/distilly

Distilly — Distill how they think into reusable Skills for any Agent or Bot. Formerly Colleague Skill（原同事 Skill）.

**项目定位**  
Distilly 是一个用于将人类思维转化为可重用技能的工具，旨在提升 AI 代理或机器人的智能表现和效率。

**核心功能**  
- 将人类思考过程转化为结构化技能  
- 支持多种 AI 模型和框架集成  
- 提供技能生成与优化机制  
- 适用于不同应用场景的技能定制  
- 支持知识蒸馏技术提升模型性能  

**技术特点**  
基于 Python 开发，结合知识蒸馏和提示工程，支持多模型适配，专注于 AI 代理技能的构建与优化。

**适用场景**  
- 构建智能客服机器人  
- 开发个性化 AI 助手  
- 提升 AI 代理的决策能力  
- 企业内部知识自动化处理  
- 研究 AI 代理与人类协作模式  

**推荐理由**  
适合希望提升 AI 代理智能水平和实用性的开发者，尤其在技能生成与知识转化方面有独特优势。
