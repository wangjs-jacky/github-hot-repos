# Agents365-ai/drawio-skill

From text & real sources to maintainable .drawio architecture models: Diagram IR with source-kind profiles, incremental sync preserving manual layout, multi-view projection, architecture-as-test with a CI action, query/review, what-if, accessible Story Mode, and a built-in MCP server

项目定位  
一个用于将文本和真实源代码转换为可维护的 .drawio 架构模型的工具，支持多种建模语言和自动化流程。

核心功能  
- 从文本和源代码生成架构图  
- 支持增量同步并保留手动布局  
- 多视图投影与架构即测试  
- 内置 MCP 服务器和 CI 流程  

技术特点  
使用 Python 实现，整合了多种建模标准如 UML、BPMN 和 C4 模型，具备自动化与可视化能力，适合复杂系统建模。

适用场景  
- 软件架构设计与文档生成  
- CI/CD 流程中的架构验证  
- 团队协作与知识共享  
- 系统迁移与重构前的可视化分析  
- 技术债务管理与审查  

推荐理由  
提供强大的自动化建模能力，支持多语言和多视图，适合需要持续维护架构图的开发团队，提升效率与一致性。
