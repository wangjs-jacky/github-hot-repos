# citrolabs/ego-lite

The fastest browser for AI agents to run browser automation, built for sharing your logged-in browser state with your AI agents, like Codex or Claude Code, without disturbing you. Zero cost, zero config.

**项目定位**  
ego-lite 是一个为 AI 代理设计的快速浏览器，允许用户在不干扰自己的情况下，共享已登录的浏览器状态给 AI 工具，如 Codex 或 Claude Code。

**核心功能**  
- 支持 AI 代理访问已登录的浏览器状态  
- 无需配置，零成本使用  
- 实现浏览器自动化操作  
- 与多种 AI 工具兼容  
- 提供安全的远程浏览器共享机制  

**技术特点**  
基于 JavaScript 构建，专注于浏览器自动化和状态共享，采用轻量级架构，确保高效运行和易用性。

**适用场景**  
- AI 开发者测试和调试代码  
- 自动化网页操作任务  
- 在不干扰用户的情况下运行 AI 代理  
- 需要持续会话状态的自动化流程  
- 快速部署 AI 代理进行网页交互  

**推荐理由**  
ego-lite 为 AI 代理提供了一种便捷、安全且高效的浏览器共享方式，适合需要自动化操作和持续会话的开发者和研究人员。
