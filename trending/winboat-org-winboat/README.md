# winboat-org/winboat

Run Windows apps on 🐧 Linux with ✨ seamless integration

项目定位  
WinBoat 是一个在 Linux 上运行 Windows 应用程序的工具，提供无缝集成体验，解决跨平台应用兼容性问题。

核心功能  
- 在 Linux 系统上运行 Windows 应用  
- 通过 RDP 实现图形界面支持  
- 使用 Docker 容器化部署  
- 支持虚拟化技术提升性能  
- 提供简单易用的配置方式

技术特点  
基于 TypeScript 开发，结合 Docker 和 RDP 技术实现跨平台应用运行，注重轻量级和易用性，适合开发者和系统管理员使用。

适用场景  
- 开发者在 Linux 环境中测试 Windows 应用  
- 企业用户需要在 Linux 服务器上运行特定 Windows 软件  
- 系统管理员部署多平台支持环境  
- 需要避免安装双系统或虚拟机的用户  
- 为 Linux 用户提供 Windows 应用兼容方案

推荐理由  
WinBoat 提供高效的 Windows 应用运行方案，简化跨平台开发与运维流程，适合需要在 Linux 中运行 Windows 软件的用户。
