# miuuyy/codex-chatgpt-web

Use ChatGPT Web (including Pro) as a native model in Codex — with context, tools, streaming and images, without using Codex quota.

项目定位  
该项目将 ChatGPT Web（包括 Pro）作为本地模型使用，支持上下文、工具、流式传输和图片，无需消耗 Codex 配额。

核心功能  
- 利用 ChatGPT Web 实现本地化模型调用  
- 支持上下文管理和工具集成  
- 实现流式响应和图片处理  
- 无需依赖 Codex 的 API 配额  

技术特点  
基于 TypeScript 开发，使用 Playwright 实现浏览器自动化，通过模拟用户操作调用 ChatGPT 功能，实现高效且低成本的 AI 对话服务。

适用场景  
- 个人开发者快速搭建 AI 对话应用  
- 企业内部测试和原型开发  
- 避免 Codex 费用的替代方案  
- 需要图像生成和流式响应的场景  
- 快速启动 AI 相关项目  

推荐理由  
该项目提供了一种无需 Codex 配额即可使用 ChatGPT 的方式，适合希望降低成本或进行本地化部署的开发者。
