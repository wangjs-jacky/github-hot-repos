# DuarteSantos8/openGym

Self-hosted gym & body-weight tracker — plan routines, log workouts (supersets, warm-ups, cardio), see which muscles are trained, fatigued or detrained, import from FitNotes/Strong/Hevy, passkey login. Your data, your server.

项目定位  
一个自托管的健身和自重训练追踪工具，帮助用户规划训练计划、记录锻炼内容，并分析肌肉状态。

核心功能  
- 计划训练计划并记录锻炼内容  
- 支持超级组、热身、有氧运动等复杂训练结构  
- 分析肌肉疲劳或退化情况  
- 支持从 FitNotes/Strong/Hevy 导入数据  
- 提供 Passkey 登录方式保障数据安全

技术特点  
基于 JavaScript 构建，使用 React 和 Vite 开发，支持 PWA 和 Docker 部署，具备良好的可扩展性和自托管能力。

适用场景  
- 个人健身爱好者管理训练计划  
- 希望避免依赖第三方应用的用户  
- 需要本地数据存储和隐私保护的用户  
- 想要通过 Web 应用进行训练记录的用户  
- 企业或团队内部部署健身追踪系统

推荐理由  
开源且自托管，注重隐私与数据控制，功能全面且支持多种训练模式，适合追求自主管理和健康追踪的用户。
