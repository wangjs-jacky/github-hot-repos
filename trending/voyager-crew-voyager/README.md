# voyager-crew/voyager

Enhancement suite for Gemini, AI Studio, Claude, ChatGPT & DeepSeek — plus a prompt manager for any website, DeepSeek Harness included. / 面向 Gemini、AI Studio、Claude、ChatGPT 与 DeepSeek 的增强套件；其中的提示词管理器可用于任意网站，如 DeepSeek Harness。

项目定位  
一个面向多个 AI 平台的增强套件，提供统一的提示词管理与功能扩展，提升用户在不同 AI 服务中的交互体验。

核心功能  
- 支持 Gemini、AI Studio、Claude、ChatGPT 与 DeepSeek 等多平台  
- 提示词管理器，适用于任意网站  
- 深度集成 DeepSeek Harness，优化模型调用  
- 浏览器扩展支持，包括 Chrome、Edge、Firefox 和 Safari  
- 集成 Chat 管理功能，提升对话效率

技术特点  
使用 TypeScript 构建，具备良好的可维护性与跨平台兼容性，结合浏览器扩展和 AI 服务 API 实现功能增强。

适用场景  
- 多 AI 平台用户需要统一管理提示词  
- 开发者需要快速测试和调用不同 AI 模型  
- 用户希望提升网页上 AI 交互的便捷性  
- 企业或团队需优化 AI 工作流效率  
- 使用 DeepSeek 的开发者需要额外功能扩展

推荐理由  
功能全面，支持多种主流 AI 平台，提供强大的提示词管理和浏览器扩展功能，适合需要高效利用 AI 工具的用户。
