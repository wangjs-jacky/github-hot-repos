# yetone/magpie

Every agent's model. One place. Codex on DeepSeek, Claude Code on Kimi, from the menu bar.

项目定位  
一个集成多种大语言模型的工具，提供统一界面访问 Codex、Claude Code、DeepSeek 等模型，方便开发者使用。

核心功能  
- 集成多个主流 LLM 模型  
- 提供统一的命令行与图形界面  
- 支持代码生成与自然语言交互  
- 适配 macOS 平台  

技术特点  
采用 Go 语言开发，注重性能与跨平台兼容性，结合多种模型接口实现统一管理，适合开发者高效调用 AI 能力。

适用场景  
- 开发者快速调用 AI 模型生成代码  
- 多模型对比测试与调试  
- 在 macOS 上集中管理 AI 工具  
- 提升日常编码效率  

推荐理由  
整合多种 AI 模型，简化开发流程，提升代码生成与调试效率，是 macOS 用户的理想工具。
