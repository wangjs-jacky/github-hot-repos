# modem-dev/hunk

Review-first terminal diff viewer for agentic coders

项目定位  
hunk 是一个以审查优先的终端差异查看器，专为代理式编码者设计，帮助开发者更高效地查看和管理代码变更。

核心功能  
- 支持 Git、Jj、Jujutsu、Sapling 等版本控制系统  
- 提供直观的终端界面进行代码差异对比  
- 专注于代码审查流程，提升协作效率  
- 可集成到开发工作流中，便于快速反馈  
- 支持多文件和大文件的差异展示

技术特点  
使用 TypeScript 构建，具备良好的跨平台兼容性；基于终端的 UI 设计，轻量且响应迅速，适合命令行环境下的代码审查需求。

适用场景  
- 开发者在终端中进行代码审查  
- 团队协作中的 PR 或 MR 审核  
- 需要快速浏览大量代码变更的场景  
- 使用非图形界面的远程开发环境  
- 集成到 CI/CD 流程中的自动化审查

推荐理由  
hunk 为代码审查提供了高效的终端工具，尤其适合注重效率和协作的开发者，支持多种版本控制工具，是代理式编码的理想选择。
