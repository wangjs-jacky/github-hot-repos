# lidge-jun/opencodex

Universal provider proxy for OpenAI Codex & Claude Code — use any LLM (Claude, Gemini, Grok, DeepSeek, Ollama…) with Codex CLI, App, SDK, and Claude Code

**项目定位**  
该项目是一个通用的 AI 模型代理服务，允许用户将多种 LLM（如 Claude、Gemini、Ollama 等）与 OpenAI Codex 兼容的工具和接口集成，解决多模型统一接入的问题。

**核心功能**  
- 支持多种 LLM 通过统一接口调用  
- 提供 CLI、App、SDK 多种使用方式  
- 实现与 Codex 和 Claude Code 的兼容  
- 可自定义代理配置和路由规则  
- 支持本地和云端部署  

**技术特点**  
基于 TypeScript 构建，具备良好的可扩展性和跨平台能力，采用模块化设计，便于集成和维护，适合开发者快速搭建 AI 代理服务。

**适用场景**  
- 开发者需要在不同 LLM 之间切换使用  
- 需要将非 OpenAI 模型接入 Codex 兼容系统  
- 构建自定义 AI 工具链或 API 服务  
- 企业希望统一管理多个 AI 服务提供商  
- 本地部署 AI 代理以提高隐私和安全性  

**推荐理由**  
该工具提供了灵活的 AI 模型代理方案，支持广泛 LLM，易于集成与扩展，适合需要多模型兼容和统一管理的开发者和企业用户。
