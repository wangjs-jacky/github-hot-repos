# shihabal3amri/DiPlay

Independent CarPlay receiver for compatible Android head units. Wired and wireless public preview.

项目定位  
DiPlay 是一个独立的 CarPlay 接收器，为兼容的 Android 车载主机提供有线和无线 CarPlay 支持，解决 Android 设备与汽车系统连接的问题。

核心功能  
- 支持有线和无线 CarPlay 连接  
- 适配多种 Android 车载主机  
- 提供稳定的音频和应用投屏功能  
- 开源且可自定义配置  

技术特点  
使用 Kotlin 编写，专注于实现 CarPlay 协议，具备良好的跨设备兼容性，适合开发者深入研究车载系统集成技术。

适用场景  
- Android 车载系统升级  
- 无原生 CarPlay 的车辆改装  
- 开发者测试 CarPlay 功能  
- 需要自定义车载体验的用户  

推荐理由  
DiPlay 是一个功能完整、开源的 CarPlay 解决方案，适合需要将 Android 设备与汽车系统无缝连接的用户和开发者。
