# Yu9191/wloc

修改 Apple 网络定位（gs-loc）返回坐标 · 支持 Surge / Quantumult X / Loon / Stash · 快捷指令一键设置/恢复定位

项目定位  
一个用于修改 Apple 网络定位的工具，支持多个代理客户端，可快速设置或恢复定位信息。

核心功能  
- 修改 Apple 网络定位（gs-loc）返回坐标  
- 支持 Surge / Quantumult X / Loon / Stash 等代理工具  
- 提供快捷指令一键操作  
- 自动化定位切换  
- 支持自定义配置文件

技术特点  
使用 JavaScript 开发，兼容多种代理平台，提供便捷的定位修改方案，具备良好的可扩展性和用户友好性。

适用场景  
- 伪装地理位置进行网络测试  
- 绕过地区限制访问内容  
- 代理工具用户需要灵活定位配置  
- 需要快速切换不同定位的开发者  
- 用于自动化脚本或快捷指令集成

推荐理由  
功能实用，兼容性强，操作简便，适合需要修改网络定位的用户和开发者，是代理工具生态中的有力补充。
