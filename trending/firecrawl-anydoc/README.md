# firecrawl/anydoc

Convert Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and PDF to clean Markdown. Built in Rust, with Node.js and Python bindings.

1. **项目定位**  
将多种文档格式转换为干净的 Markdown，解决文档内容提取与格式统一问题。

2. **核心功能**  
- 支持 Word、PowerPoint、Excel 等多种格式转 Markdown  
- 提供 Rust 原生实现，确保高性能  
- 支持 Node.js 和 Python 绑定，方便集成  
- 保留原文本结构和内容，去除冗余格式  

3. **技术特点**  
基于 Rust 构建，兼顾性能与安全性，同时提供多语言绑定，适合需要高效文档处理的场景。

4. **适用场景**  
- 文档内容提取与分析  
- 博客或知识库内容生成  
- 多格式文件统一处理  
- 自动化数据导入与导出  
- 跨平台文档转换工具  

5. **推荐理由**  
功能全面、性能优异，支持多种文档格式转换，适合开发者和内容创作者提升工作效率。
