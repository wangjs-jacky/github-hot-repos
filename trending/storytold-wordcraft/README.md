# storytold/wordcraft

An open-source, clean-room reimplementation of Microsoft Word in pure Rust

项目定位  
一个用 Rust 语言实现的开源 Microsoft Word 替代品，旨在提供干净、安全且高效的文档处理功能。

核心功能  
- 支持 DOCX 文档格式读写  
- 提供基本的文本编辑和排版功能  
- 实现与 Word 类似的用户界面体验  
- 可扩展的插件系统  

技术特点  
使用 Rust 编写，强调内存安全和性能，采用模块化设计，便于维护和扩展，符合现代软件开发标准。

适用场景  
- 需要替代 Microsoft Word 的轻量级办公需求  
- 对安全性要求高的文档处理任务  
- 开发者希望研究或参与开源办公软件项目  
- 教育或研究用途，学习文档处理技术  

推荐理由  
作为一款纯 Rust 实现的 Word 替代品，它在安全性、性能和可扩展性方面表现突出，适合开发者和需要可靠文档工具的用户。
