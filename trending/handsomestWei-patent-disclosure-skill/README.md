# handsomestWei/patent-disclosure-skill

中国专利.skill：专利点挖掘与交底书（发明/实用/外观）编写，通俗解读专利，嗅探政策动向，辅助审查答复。

项目定位  
一个帮助用户挖掘专利点、撰写交底书并解读专利的工具，专注于中国专利领域，提升专利申请与管理效率。

核心功能  
- 专利点挖掘与分析  
- 交底书（发明/实用/外观）模板生成  
- 专利政策动态嗅探  
- 审查答复辅助建议  
- 通俗化专利知识解读

技术特点  
基于 Python 开发，结合自然语言处理和数据抓取技术，提供智能化的专利分析与写作支持，适合非专业用户快速上手。

适用场景  
- 企业研发人员撰写专利  
- 法律从业者辅助客户  
- 高校科研团队进行成果转化  
- 创业者保护创新成果  
- 政策研究者跟踪专利趋势

推荐理由  
为中文用户提供一站式专利服务，降低专利申请门槛，提升撰写质量与效率，是创新保护的重要工具。
