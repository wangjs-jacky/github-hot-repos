# kangarooking/cangjie-skill

把书、长视频、播客等高价值内容蒸馏成可执行的 Agent Skills

项目定位  
将书籍、视频、播客等高价值内容转化为可执行的 AI Agent 技能，提升知识利用效率。

核心功能  
- 内容蒸馏为结构化技能模板  
- 支持多种内容格式输入（书、视频、播客）  
- 生成可调用的 AI 技能代码  
- 提供 Prompt 工程与自动化流程支持  
- 适用于构建智能助手和自动化工作流

技术特点  
基于 Python 实现，结合知识蒸馏与 Prompt 工程，提供模块化架构，便于扩展和定制 AI 技能。

适用场景  
- 个人知识管理与自动化  
- 企业内部知识库构建  
- 智能客服与问答系统开发  
- 教育内容自动化处理  
- AI 助手技能扩展

推荐理由  
项目聚焦知识转化与 AI 应用，适合希望将信息快速转化为实用技能的开发者与研究者，具有较强的实用性和创新性。
