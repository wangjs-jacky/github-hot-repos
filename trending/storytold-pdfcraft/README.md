# storytold/pdfcraft

PdfCraft: An open-source PDF reader and editor written by scratch in pure Rust

**项目定位**  
PdfCraft 是一个用 Rust 编写的开源 PDF 阅读器和编辑器，旨在提供轻量级、高性能的 PDF 处理工具。

**核心功能**  
- 支持 PDF 文件的阅读与浏览  
- 提供基本的 PDF 编辑功能  
- 实现 PDF 文档的生成与处理  
- 采用纯 Rust 编写，无外部依赖  

**技术特点**  
PdfCraft 用 Rust 从零构建，注重性能与安全性，适合需要高效文档处理的场景，同时具备良好的跨平台兼容性。

**适用场景**  
- 开发者需要在 Rust 环境中处理 PDF  
- 需要轻量级 PDF 工具的用户  
- 对 PDF 生成或编辑有特定需求的项目  
- 希望使用开源工具替代商业 PDF 软件的场景  

**推荐理由**  
PdfCraft 是一个高性能、开源且用 Rust 编写的 PDF 工具，适合需要自定义文档处理能力的开发者和用户。
