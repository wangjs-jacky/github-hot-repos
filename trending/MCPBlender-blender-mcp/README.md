# MCPBlender/blender-mcp

🎨 Control Blender 3D with Claude AI — prompt-driven 3D modeling, materials & scene generation via MCP

项目定位  
MCPBlender/blender-mcp 是一个将 Claude AI 与 Blender 3D 建模工具结合的插件，通过提示驱动的方式实现自动化建模、材质和场景生成。

核心功能  
- 通过自然语言提示控制 Blender 3D 模型生成  
- 支持材质和场景的自动创建  
- 利用 MCP 协议进行模型上下文交互  
- 提供用户友好的 Blender 插件集成  
- 实现 AI 与 3D 建模工具的无缝连接

技术特点  
该项目基于 Python 开发，利用 MCP 协议与 Claude AI 对接，实现 Blender 的扩展功能，具备良好的可定制性和用户交互体验。

适用场景  
- 3D 艺术创作与设计  
- 游戏场景快速生成  
- 产品原型设计  
- 教育与培训中的 AI 辅助建模  
- 自动化内容生成工作流

推荐理由  
该插件为 Blender 用户提供了强大的 AI 驱动建模能力，适合希望提升创作效率和探索 AI 与 3D 设计结合可能性的开发者和艺术家。
