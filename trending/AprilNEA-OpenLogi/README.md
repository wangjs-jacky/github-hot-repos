# AprilNEA/OpenLogi

⚡️A native, local-first alternative to Logitech Options+, written in Rust 🦀 — remap buttons, DPI, and SmartShift over HID++. No account, no telemetry.

项目定位  
OpenLogi 是一个本地优先的 Logitech Options+ 替代方案，使用 Rust 编写，用于重新映射鼠标按钮、DPI 和 SmartShift 功能，无需账户或数据追踪。

核心功能  
- 鼠标按钮自定义映射  
- DPI 调整与配置  
- SmartShift 功能支持  
- 通过 HID++ 协议与 Logitech 设备通信  
- 本地运行，无云端依赖

技术特点  
使用 Rust 编写，注重安全性和性能，通过 HID++ 协议直接与设备交互，实现本地化、隐私保护的鼠标配置方案。

适用场景  
- 需要自定义鼠标功能的开发者  
- 关注隐私的用户  
- 使用 Logitech 鼠标的游戏玩家  
- 希望替代 Logitech Options+ 的用户  
- 需要本地化配置工具的办公环境

推荐理由  
OpenLogi 提供了高效、隐私友好的 Logitech 鼠标配置方案，基于 Rust 构建，稳定且安全，是 Logitech Options+ 的理想替代品。
