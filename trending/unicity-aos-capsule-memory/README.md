# unicity-aos/capsule-memory

Cross-session memory. Reads local memory state and injects it into the system prompt through hooks. Part of Unicity AOS.

**项目定位**  
一个用于跨会话记忆管理的系统，通过钩子将本地内存状态注入系统提示，增强AI系统的上下文连续性。

**核心功能**  
- 读取本地内存状态  
- 通过钩子注入系统提示  
- 支持跨会话数据持久化  
- 与Unicity AOS集成  

**技术特点**  
使用 Rust 编写，注重性能与安全性，提供高效的内存管理和钩子机制，适合系统级应用开发。

**适用场景**  
- AI 系统的上下文管理  
- 需要持久化会话状态的应用  
- 开发定制化操作系统模块  
- 提升多任务处理能力  

**推荐理由**  
轻量高效，适合需要跨会话记忆支持的系统开发，尤其适合对性能和稳定性有要求的项目。
