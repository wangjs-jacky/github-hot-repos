# storytold/lightcraft

LightCraft: An open-source non-destructive photo editor written by scratch in pure Rust

项目定位  
LightCraft 是一款用 Rust 编写的开源非破坏性照片编辑器，专注于提供高效、安全的图像处理体验。

核心功能  
- 非破坏性编辑，支持图层和调整层  
- RAW 图像处理与后期修图  
- 支持多种图像格式导入与导出  
- 实时预览与高性能渲染  
- 简洁直观的用户界面

技术特点  
LightCraft 采用 Rust 语言开发，确保内存安全与高性能，同时具备良好的跨平台兼容性，适合专业摄影与图像处理需求。

适用场景  
- 摄影师进行 RAW 文件后期处理  
- 图像设计师进行非破坏性编辑  
- 开发者研究 Rust 在图像处理中的应用  
- 用户需要轻量级且高效的图像工具  
- 对隐私和数据安全有较高要求的用户

推荐理由  
LightCraft 提供了高效的非破坏性编辑功能，结合 Rust 的性能优势，是摄影爱好者和专业用户的理想选择。
