# firecrawl/pdf-inspector

Fast Rust library for PDF inspection, classification, and text extraction. Intelligently detects scanned vs text-based PDFs to enable smart routing decisions.

项目定位  
一个快速的 Rust 库，用于 PDF 检查、分类和文本提取，智能区分扫描版与文本版 PDF，以实现智能路由决策。

核心功能  
- PDF 分类：识别扫描版或文本版 PDF  
- 文本提取：高效提取 PDF 中的文本内容  
- 智能路由：根据 PDF 类型进行智能处理路径选择  
- 支持多种格式解析  

技术特点  
基于 Rust 开发，性能高、内存安全，支持多语言集成，具备高效的 OCR 路由逻辑，适用于需要快速处理 PDF 的场景。

适用场景  
- PDF 内容分析与处理系统  
- 文件归档与信息提取工具  
- 自动化文档处理流程  
- 需要区分扫描与文本 PDF 的应用  

推荐理由  
高性能、安全的 Rust 实现，结合智能 PDF 分类与提取功能，适合需要高效处理 PDF 的开发者和企业使用。
