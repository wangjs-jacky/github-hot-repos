# robbietilton/Compositor

The Photoshop alternative for Mac

项目定位  
Compositor 是一款为 Mac 用户提供的 Photoshop 替代软件，旨在提供强大的图像编辑功能，满足专业设计和创意需求。

核心功能  
- 图像编辑与修饰  
- 多图层支持与管理  
- 高级滤镜与效果  
- 画笔与绘图工具  
- 支持多种图像格式

技术特点  
使用 Swift 编写，具备良好的性能和 macOS 系统集成，采用现代图形处理技术，确保高效的图像渲染和操作体验。

适用场景  
- 平面设计与视觉创作  
- 图片后期处理与修图  
- 数字艺术创作  
- 专业摄影后期  
- 个人或小型团队图像编辑需求

推荐理由  
Compositor 为 Mac 用户提供了功能强大且易于使用的图像编辑工具，是 Photoshop 的优质替代方案，尤其适合追求高效与创意自由的用户。
