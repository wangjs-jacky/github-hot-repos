# AgriciDaniel/claude-ads

Claude-first paid-media operations skill for Claude Code across 12 ad platforms (Google, Meta, YouTube, LinkedIn, TikTok, Microsoft, Apple, Amazon, Reddit, Pinterest, Snapchat, X): source-grounded audits, deterministic scoring, versioned JSON reports, and capability-gated account changes.

项目定位  
一个为 Claude Code 设计的付费广告操作技能，支持 12 个主流广告平台，提供审计、评分和报告功能，提升广告运营效率。

核心功能  
- 跨平台广告操作支持（Google、Meta、YouTube 等）  
- 源代码驱动的审计与评分系统  
- 版本化 JSON 报告生成  
- 基于能力的账户变更控制  

技术特点  
使用 Python 实现，结合 AI 和自动化技术，支持多平台 API 集成，具备可扩展性和可维护性。

适用场景  
- 广告运营团队自动化任务  
- 多平台广告策略分析  
- 企业级广告账户管理  
- AI 驱动的广告优化实验  
- 开源社区贡献与学习  

推荐理由  
适合需要跨平台广告管理与优化的用户，提供高效、可审计的 AI 支持工具，适合营销技术人员和开源爱好者。
