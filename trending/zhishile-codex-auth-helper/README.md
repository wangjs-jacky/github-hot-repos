# zhishile/codex-auth-helper

Codex登陆助手：安全地在本地导出您的已登录 ChatGPT 会话配置，生成符合 Codex 规范的 auth.json 本地备份文件。

项目定位  
一个用于安全导出 ChatGPT 登录会话配置并生成 Codex 兼容 auth.json 文件的工具，帮助用户备份登录信息。

核心功能  
- 安全导出已登录 ChatGPT 的会话配置  
- 生成符合 Codex 规范的 auth.json 文件  
- 无需暴露敏感信息即可完成备份  

技术特点  
使用 CSS 实现前端交互，专注于本地文件处理与格式转换，确保数据安全和兼容性。

适用场景  
- 开发者需要备份 ChatGPT 登录状态  
- 使用 Codex 工具时需提供 auth.json 文件  
- 避免重复登录或丢失会话数据  

推荐理由  
简化 ChatGPT 登录信息的备份流程，提升开发效率与安全性，适合 Codex 用户必备工具。
