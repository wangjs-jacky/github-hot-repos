# storytold/photocraft

An open-source, clean-room reimplementation of Adobe Photoshop in pure Rust

项目定位  
一个用 Rust 语言实现的开源 Photoshop 克隆项目，旨在提供功能完整的图像编辑工具，不依赖 Adobe 的专有技术。

核心功能  
- 支持 PSD 文件格式读写  
- 提供基本的图像编辑功能如图层、滤镜、调整工具  
- 实现类似 Photoshop 的用户界面和操作逻辑  
- 支持多种图像格式导入导出  
- 开发中的 AI 功能集成  

技术特点  
使用 Rust 实现高性能和内存安全，采用模块化设计，注重代码可维护性和跨平台兼容性，目标是构建一个现代、高效的图像编辑软件。

适用场景  
- 图像编辑爱好者寻找替代方案  
- 开发者研究图像处理算法和 UI 架构  
- 需要无依赖的图像编辑工具的团队  
- 对开源图像软件感兴趣的教育用途  
- 希望参与图像处理技术开发的社区贡献者

推荐理由  
Photocraft 是一个有潜力的开源 Photoshop 替代品，适合需要高性能、安全且可定制图像编辑工具的用户和开发者，具有良好的技术基础和活跃的社区支持。
