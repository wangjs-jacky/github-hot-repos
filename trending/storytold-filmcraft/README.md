# storytold/filmcraft

FilmCraft: An open-source, nonlinear video editor written by scratch in pure Rust

**项目定位**  
FilmCraft 是一个用 Rust 编写的开源非线性视频编辑器，旨在提供高效、可靠的视频处理和编辑功能。

**核心功能**  
- 支持多轨道视频剪辑与合成  
- 提供丰富的视频效果和转场  
- 实时预览与导出功能  
- 轻量级且可扩展的架构  

**技术特点**  
使用纯 Rust 编写，注重性能与安全性，采用现代视频处理算法，确保高效流畅的编辑体验。

**适用场景**  
- 个人视频创作与剪辑  
- 开发者进行视频处理工具研究  
- 专业视频团队的轻量级编辑需求  
- 对性能和安全有高要求的视频应用  

**推荐理由**  
FilmCraft 凭借其 Rust 技术栈和开源特性，为视频编辑领域提供了高性能、可信赖的替代方案，适合开发者和创作者使用。
