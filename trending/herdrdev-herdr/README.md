# herdrdev/herdr

agent multiplexer that lives in your terminal.

项目定位  
herdr 是一个终端中的代理多路复用器，用于管理多个 AI 代理，提升开发者在终端中的工作效率。

核心功能  
- 管理多个 AI 代理并进行交互  
- 支持多种 AI 模型和 API 集成  
- 提供终端内的 UI 界面操作  
- 自动化任务流程与代理协作  
- 支持自定义代理配置与工作流

技术特点  
使用 Rust 编写，具备高性能和安全性，支持跨平台运行，结合 TUI 技术提供直观的终端交互体验。

适用场景  
- 开发者在终端中同时调用多个 AI 工具  
- 自动化代码生成与调试流程  
- 多代理协同开发与测试  
- 提升命令行工具的智能化水平  
- 构建 AI 驱动的开发环境

推荐理由  
herdr 通过整合多个 AI 代理，简化了终端中的开发流程，提升了效率，适合需要高效利用 AI 工具的开发者。
