# every-app/open-seo

Open source alternative to Semrush and Ahrefs

项目定位  
一个开源的 SEO 工具，替代 Semrush 和 Ahrefs，提供关键词研究、网站审计、反向链接分析等功能。

核心功能  
- 关键词研究与分析  
- 网站健康度审计  
- 反向链接分析  
- Google 搜索控制台集成  
- SEO 优化建议

技术特点  
使用 TypeScript 构建，具备良好的类型安全和可维护性，支持现代 Web 开发实践，适合构建高性能的 SEO 工具。

适用场景  
- 个人博客或小型网站的 SEO 优化  
- 数字营销团队进行关键词分析  
- 网站管理员进行定期站点审核  
- 需要替代付费 SEO 工具的开发者  
- 企业进行竞品 SEO 分析

推荐理由  
开源且功能全面，适合需要低成本、高灵活性的 SEO 工具用户，尤其适合开发者和 SEO 从业者。
