# cloudflare/security-audit-skill

A coding-agent skill for multi-phase security audits with independently verified, machine-readable findings

项目定位  
一个用于多阶段安全审计的代码代理技能，提供可验证、机器可读的安全发现结果。

核心功能  
- 支持多阶段自动化安全审计流程  
- 生成独立验证的安全评估报告  
- 提供结构化、可编程的安全发现数据  
- 与安全工具集成以增强检测能力  
- 便于开发者和安全团队协作使用

技术特点  
基于 JavaScript 构建，具备良好的扩展性和集成能力，支持自动化安全扫描与分析，强调结果的可验证性与机器可读性。

适用场景  
- 企业级应用安全审计  
- 开源项目安全检查  
- 安全团队自动化工作流  
- 安全漏洞持续监控  
- 开发者安全实践辅助

推荐理由  
适合需要高效、可靠安全审计工具的开发与安全团队，提供结构化、可验证的审计结果，提升安全工作的透明度与效率。
