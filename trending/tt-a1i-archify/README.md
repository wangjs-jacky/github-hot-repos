# tt-a1i/archify

Agent skill for beautiful, verifiable architecture, workflow, sequence, data-flow, and lifecycle diagrams—self-contained HTML with motion and crisp export.

项目定位  
archify 是一个用于生成可验证架构、流程、数据流等图示的代理技能工具，通过自包含的 HTML 实现清晰且动态的可视化效果。

核心功能  
- 支持架构图、流程图、数据流图等多种图表类型  
- 生成自包含 HTML 文件，无需依赖外部服务  
- 提供动画效果和清晰导出功能  
- 支持暗色模式与多种设计风格  

技术特点  
基于 HTML 构建，结合 SVG 和 JavaScript 实现动态图表，支持在不依赖第三方库的情况下生成高质量可视化内容。

适用场景  
- 软件开发中的系统设计文档  
- 技术团队内部的流程说明  
- 教育或演示用途的可视化展示  
- 需要独立部署和导出的图表需求  

推荐理由  
archify 提供了一种轻量、自包含且功能强大的方式来创建和分享各种类型的图表，适合开发者和设计师在不同场景中使用。
