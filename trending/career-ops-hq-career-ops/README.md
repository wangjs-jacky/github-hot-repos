# career-ops-hq/career-ops

Open-source AI job search: scan job portals, evaluate listings into a structured A-H report with a global 1-5 score, tailor your CV, track applications — runs locally in your AI coding CLI (Claude Code, Codex, OpenCode, Antigravity…)

项目定位  
一个开源 AI 驱动的求职工具，帮助用户扫描招聘网站、评估职位并优化简历，提升求职效率。

核心功能  
- 自动扫描多个招聘平台  
- 生成结构化 A-H 报告和全球评分  
- 根据职位定制简历  
- 跟踪申请状态  
- 支持本地 CLI 运行

技术特点  
使用 JavaScript 构建，支持多种 AI 编程环境，注重本地运行与自动化，适合开发者快速上手和贡献。

适用场景  
- 求职者优化简历和申请流程  
- 开发者参与开源项目开发  
- 企业招聘人员筛选职位  
- 学生准备面试和职业规划  
- 自动化求职任务管理

推荐理由  
功能全面且易于使用，适合求职者和开发者，结合 AI 技术提升求职效率，开源社区活跃，适合参与贡献。
