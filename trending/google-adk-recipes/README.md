# google/adk-recipes

A collection of sample agents built with Agent Development Kit (ADK) 

项目定位  
该仓库是用于构建智能代理的示例集合，基于 Agent Development Kit (ADK) 提供开发参考。

核心功能  
- 提供多种代理示例，展示不同功能实现  
- 展示 ADK 的核心 API 使用方式  
- 包含交互逻辑、任务处理等基础功能  
- 支持模块化设计，便于扩展和定制  
- 提供测试和运行指南

技术特点  
使用 Python 开发，基于 ADK 构建，强调模块化与可扩展性，适合快速构建和测试智能代理应用。

适用场景  
- 教学与学习 ADK 的使用方法  
- 快速搭建智能代理原型  
- 研究代理系统的交互逻辑  
- 企业内部智能流程自动化开发  
- 研究 AI 代理在实际场景中的应用

推荐理由  
适合开发者学习和实践 ADK，提供丰富的示例和清晰的结构，有助于快速上手智能代理开发。
