# codewhale-hq/Codewhale

Open-source coding agent for your terminal, built in Rust and on a journey of continuous community improvement. Issues and PRs welcome.

项目定位  
Codewhale 是一个开源的终端代码代理，基于 Rust 构建，旨在通过 AI 技术提升开发者在本地环境中的编码效率。

核心功能  
- 通过 AI 协助编写、调试和优化代码  
- 支持多模型和多代理协作  
- 提供命令行界面（CLI）和 TUI 界面  
- 集成本地开发环境，实现“本地优先”体验  
- 支持社区驱动的持续改进

技术特点  
使用 Rust 编写，注重性能与安全性，支持多代理架构和本地运行，强调开放性和可扩展性。

适用场景  
- 开发者在终端中进行高效代码编写  
- 需要本地运行的 AI 辅助开发工具  
- 多模型协作的 AI 编程实验  
- 希望参与开源项目的开发者  
- 需要轻量级、快速响应的 CLI 工具

推荐理由  
Codewhale 是一个高性能、可扩展的开源代码代理，适合希望提升本地开发效率并参与 AI 编程创新的开发者。
