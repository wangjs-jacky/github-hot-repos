# eternity4719/HowToLiveBetter

按性价比排序的循证生活指南：长寿防病、急救、省钱理财、法律红线、失业与工伤、医保社保、恋爱婚育、怀孕育儿、创业与做平台合规、出国与技能。每条写明成本、收益、证据等级和原始出处，只引期刊论文与官方文件。

项目定位  
一个基于循证医学和官方文件的生活指南项目，提供高性价比的实用生活建议，涵盖健康、财务、法律等多个领域。

核心功能  
- 提供按性价比排序的生活建议  
- 每项建议注明成本、收益、证据等级及原始出处  
- 聚焦长寿防病、急救、理财、法律等实用主题  
- 引用权威期刊论文与官方文件作为依据  

技术特点  
项目以 HTML 为主，结构清晰，内容易于阅读和分享，适合快速获取信息，无复杂交互设计。

适用场景  
- 个人健康管理参考  
- 理财与法律知识学习  
- 准备应急情况的实用指南  
- 为家庭决策提供科学依据  

推荐理由  
内容严谨、来源可靠，覆盖广泛生活领域，适合追求高效、低成本提升生活质量的用户。
