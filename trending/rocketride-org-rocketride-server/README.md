# rocketride-org/rocketride-server

High-performance AI pipeline engine with a C++ core and 50+ Python-extensible nodes. Build, debug, and scale LLM workflows with 13+ model providers, 8+ vector databases, and agent orchestration, all from your IDE. Includes VS Code extension, TypeScript/Python SDKs, and Docker deployment.

项目定位  
一个高性能 AI 管道引擎，支持 C++ 核心与 Python 扩展节点，用于构建、调试和扩展大型语言模型工作流。

核心功能  
- 支持 13+ 模型提供商和 8+ 向量数据库  
- 提供 Python 和 TypeScript SDK 及 VS Code 插件  
- 实现代理编排和本地 IDE 开发环境集成  
- 支持 Docker 部署和大规模扩展  

技术特点  
采用 C++ 核心确保高性能，Python 可扩展性强，结合 TypeScript 和 VS Code 提升开发体验，适合复杂 AI 工作流管理。

适用场景  
- 企业级 AI 流水线开发  
- 多模型协同推理系统  
- 本地化部署与调试  
- 大规模 LLM 工作流管理  

推荐理由  
提供完整的 AI 工作流工具链，兼顾性能与灵活性，适合需要高效开发和部署 AI 应用的开发者和团队。
