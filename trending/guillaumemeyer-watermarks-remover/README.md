# guillaumemeyer/watermarks-remover

Strip multi-vendor AI provenance marks: Unicode text hygiene, statistical rewrite hooks, and C2PA/metadata from PNG/JPEG/SVG/PDF/DOCX/HTML/MD

项目定位  
一个用于移除多供应商 AI 生成内容中水印、元数据和溯源信息的工具，解决 AI 内容的不可控痕迹问题。

核心功能  
- 移除 PNG/JPEG/SVG/PDF/DOCX/HTML/MD 中的水印和元数据  
- 支持 C2PA 和其他 AI 证明技术的擦除  
- 提供统计重写钩子，修改内容以规避检测  
- 清理 Unicode 文本中的 AI 轨迹信息  

技术特点  
基于 Python 实现，支持多种文件格式处理，结合文本清洗与元数据操作，具备较强的 AI 溯源信息清除能力。

适用场景  
- 研究 AI 生成内容的可逆性  
- 隐私保护与内容去标识化  
- 内容再利用与版权合规处理  
- 安全测试与对抗性分析  

推荐理由  
功能全面，支持多格式和多种 AI 水印类型，适合需要清理 AI 生成内容痕迹的开发者和研究人员使用。
