# unicity-aos/capsule-identity

System prompt builder. Assembles agent identity from workspace config and spark.toml. Part of Unicity AOS.

项目定位  
一个用于构建智能体身份的系统提示生成工具，通过整合工作区配置和 spark.toml 文件，为 Unicity AOS 提供身份定义支持。

核心功能  
- 从配置文件中提取 agent 身份信息  
- 根据 spark.toml 生成系统提示  
- 支持多环境配置管理  
- 提供统一的身份构建流程  
- 与 Unicity AOS 紧密集成

技术特点  
使用 Rust 编写，注重性能与安全性，采用模块化设计，便于扩展和维护，适合构建高效、稳定的系统工具。

适用场景  
- 智能体开发与部署  
- 自动化系统提示生成  
- 多环境配置管理  
- 集成到 DevOps 流程  
- 构建 AI 驱动的协作系统

推荐理由  
轻量高效，专注于智能体身份构建，适合需要灵活配置和高可扩展性的 AI 开发者和团队使用。
