# simonlin1212/a-stock-data

A股全栈数据工具包 · 10层架构 · 43端点(含3官方备胎) · 15数据源 · 行情/研报/资金面/筹码/公告/打板/ETF期权/舆情互动全覆盖+备用源降级 | China A-Share full-stack data toolkit (43 endpoints)

**项目定位**  
A股全栈数据工具包，提供多维度金融数据支持，覆盖行情、研报、资金面等，满足量化分析与投资研究需求。

**核心功能**  
- 提供43个数据端点，涵盖A股市场全方位数据  
- 包含15个数据源，保障数据稳定性和可靠性  
- 支持行情、研报、资金流、筹码分布等多类数据查询  
- 含官方备用数据源，确保数据可用性  

**技术特点**  
采用分层架构设计，具备良好的扩展性与稳定性，支持多种数据获取方式，适合金融数据分析场景。

**适用场景**  
- 量化交易策略开发  
- 股票市场研究与分析  
- 金融数据可视化与建模  
- AI模型训练与金融知识库构建  
- 企业内部数据系统搭建  

**推荐理由**  
功能全面、数据丰富、架构清晰，适合金融从业者和量化开发者使用，提升数据获取与分析效率。
