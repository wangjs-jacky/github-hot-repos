# unicity-aos/capsule-fs

Filesystem tools for agents. Read, write, replace, grep, list, create, delete, move via VFS airlock. Part of Unicity AOS.

项目定位  
一个用于代理系统的文件系统工具库，提供多种文件操作功能，通过 VFS 空中走廊实现安全的文件管理。

核心功能  
- 读取文件内容  
- 写入和替换文件  
- 搜索匹配内容（grep）  
- 列出文件列表  
- 创建、删除和移动文件  

技术特点  
使用 Rust 编写，注重安全性和性能，通过 VFS 空中走廊实现隔离的文件操作，适合嵌入式或代理环境。

适用场景  
- 代理系统中的文件管理  
- 安全敏感环境下的文件操作  
- 自动化脚本与工具开发  
- 嵌入式系统中的文件处理  
- 跨平台文件操作需求  

推荐理由  
提供安全、高效的文件操作功能，适合需要隔离和控制的代理系统或自动化工具，代码质量高且语言选择合理。
