# tradecatlabs/vibe-coding-cn

Vibe Coding 从入门到精通教程｜AI 结对编程工作流｜Prompt、Skill、Workflow、上下文管理、codex实战指南

项目定位  
Vibe Coding 教程，聚焦 AI 编程工作流，提供从入门到精通的 AI 编程指导与实战指南。

核心功能  
- AI 编程工作流教学  
- Prompt 工程与技能训练  
- 上下文管理与 codex 实战  
- 代码生成与调试技巧  
- 多 AI 工具（如 Claude, Codex）集成使用

技术特点  
基于 Python，融合 AI 编程工具与实践方法，强调高效编码与智能协作，适合开发者提升编程效率。

适用场景  
- AI 编程初学者学习路径  
- 提升代码生成与调试能力  
- 探索 AI 辅助开发工具的使用  
- 构建个人 AI 编程工作流  
- 中文开发者获取 AI 编程资源

推荐理由  
全面覆盖 AI 编程知识体系，结合实战与工具应用，是中文开发者学习 AI 编程的优质资源。
