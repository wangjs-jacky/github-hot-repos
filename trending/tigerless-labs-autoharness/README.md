# tigerless-labs/autoharness

Autoharness — a self-learning skill layer for Claude Code — distills skills from your real sessions, updates them as you work, and prunes the ones that stop getting used. No daemon, no benchmark.

**项目定位**  
Autoharness 是一个为 Claude Code 设计的自我学习技能层，通过用户实际操作会话提炼技能，并持续更新和优化这些技能。

**核心功能**  
- 从真实用户会话中提炼技能  
- 自动更新技能以适应用户工作流程  
- 定期修剪不再使用的技能  
- 无需后台进程或基准测试  

**技术特点**  
使用 Python 实现，专注于高效技能管理与自适应学习，结合 LLM 代理能力提升代码开发效率。

**适用场景**  
- 开发者在使用 Claude Code 时提升效率  
- 需要动态调整技能库的自动化任务  
- 优化长期运行的 AI 代理系统  
- 减少重复性技能训练成本  

**推荐理由**  
Autoharness 提供了一种轻量且高效的技能管理方式，适合希望提升 AI 编程助手使用体验的开发者。
