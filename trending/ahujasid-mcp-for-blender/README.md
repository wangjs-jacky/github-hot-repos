# ahujasid/mcp-for-blender

Community plugin to control Blender 3D with any LLM of your choice

项目定位  
一个社区插件，允许用户通过任意大语言模型控制 Blender 3D 软件，提升 3D 建模效率。

核心功能  
- 支持多种 LLM 接入，如 Claude、GPT 等  
- 提供自然语言指令控制 Blender 操作  
- 实现 3D 模型生成与编辑的自动化流程  
- 支持自定义脚本扩展功能  
- 与 Blender 的 API 集成紧密

技术特点  
基于 Python 开发，采用 Model-Context-Protocol (MCP) 协议实现与 LLM 的交互，具备良好的可扩展性和兼容性。

适用场景  
- 3D 艺术家快速生成模型  
- 游戏开发中自动化建模流程  
- 教育领域用于教学演示  
- AI 与 3D 设计结合的创新实验  
- 个人创作者提升工作效率

推荐理由  
提供灵活的 LLM 集成方式，显著提升 Blender 的智能化水平，适合需要高效 3D 创作与 AI 结合的用户。
