# Imbad0202/academic-research-skills-codex

Codex-native Academic Research Skills suite for human-in-the-loop academic research workflows

项目定位  
一个基于 Codex 的学术研究技能套件，旨在辅助人类在循环中的学术研究流程，提升研究效率和质量。

核心功能  
- 自动化文献综述生成  
- 学术写作与润色支持  
- 研究流程自动化与管理  
- 用于论文审稿的智能辅助  
- 提示工程优化研究流程

技术特点  
采用 Python 编写，集成 OpenAI Codex API，专注于提升学术研究中的人机协作效率，具备良好的可扩展性和模块化设计。

适用场景  
- 学术研究人员日常写作与整理  
- 论文初稿生成与修改  
- 文献检索与综述撰写  
- 同行评审辅助  
- 研究流程优化与自动化

推荐理由  
适合需要提升学术研究效率的学者和研究人员，提供从文献到写作的一站式 AI 辅助工具，尤其适用于依赖提示工程的科研工作流。
