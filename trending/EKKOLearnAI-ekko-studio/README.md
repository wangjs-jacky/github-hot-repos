# EKKOLearnAI/ekko-studio

Ekko Studio is a local-first AI workspace for multi-agent chat, coding, and visual workflows, available on desktop and the web.

项目定位  
Ekko Studio 是一个本地优先的 AI 工作空间，支持多智能体聊天、编码和可视化工作流，适用于桌面和网页端。

核心功能  
- 多智能体聊天交互  
- 编码辅助与自动化  
- 可视化工作流设计  
- 跨平台支持（桌面与网页）  
- 自托管部署选项

技术特点  
基于 TypeScript 和 Vue3 构建，支持多模型、多平台，强调本地优先和自托管能力，具备良好的扩展性与可定制性。

适用场景  
- 个人开发者进行 AI 编程与调试  
- 团队协作中的多智能体任务管理  
- 需要本地部署的隐私敏感型应用  
- 企业级工作流自动化  
- 快速构建 AI 应用原型

推荐理由  
Ekko Studio 提供强大的多智能体支持和跨平台能力，适合需要本地部署和高度定制的 AI 开发者与团队。
