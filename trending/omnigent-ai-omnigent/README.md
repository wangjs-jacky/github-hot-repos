# omnigent-ai/omnigent

Omnigent is an open-source AI agent framework and meta-harness: orchestrate Claude Code, Codex, Cursor, Pi, and custom agents — swap harnesses without rewriting, enforce policies and sandboxing, and collaborate in real time from any device.

**项目定位**  
Omnigent 是一个开源的 AI 代理框架和元工具，用于协调多个 AI 模型和自定义代理，实现策略控制、沙盒隔离和实时协作。

**核心功能**  
- 支持多种 AI 模型（如 Claude Code、Codex）的集成与调度  
- 提供策略控制和沙盒机制以增强安全性  
- 实现多代理协作与实时交互  
- 允许在不重写代码的情况下切换不同代理架构  

**技术特点**  
基于 Python 构建，具备模块化设计和灵活的扩展性，支持跨平台部署和多代理协同工作，注重安全性和可管理性。

**适用场景**  
- 开发者工具链中集成 AI 代理  
- 多模型协作的 AI 项目管理  
- 安全敏感环境下的 AI 应用开发  
- 实时多人协作的 AI 任务处理  

**推荐理由**  
Omnigent 提供了强大的 AI 代理协调能力，适合需要多模型整合和安全控制的开发者，是构建复杂 AI 应用的理想选择。
