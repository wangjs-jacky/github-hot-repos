# Vincentwei1021/video-shotcraft

AI video skill for Claude Code & Codex — cinematic product videos with Remotion: 152 shot recipe cards, 209 motion previews, a production-ready template

项目定位  
一个基于 Remotion 的 AI 视频生成工具，专为 Claude Code 与 Codex 设计，提供电影级产品视频制作方案。

核心功能  
- 提供 152 个镜头模板，方便快速构建视频内容  
- 支持 209 个动态预览，提升视频创作效率  
- 提供可直接用于生产的视频模板  
- 利用 AI 技术自动化生成高质量视频  
- 与 Claude Code 及 Codex 深度集成

技术特点  
使用 TypeScript 构建，结合 Remotion 框架实现高效视频生成，支持 AI 驱动的动态内容创作，具备良好的扩展性和生产可用性。

适用场景  
- 产品宣传视频制作  
- 电商广告视频生成  
- 社交媒体内容创作  
- 品牌推广视频开发  
- 快速原型视频演示

推荐理由  
适合需要快速生成高质量产品视频的开发者和设计师，尤其适合与 Claude 系列工具结合使用，提升视频制作效率和创意表现力。
